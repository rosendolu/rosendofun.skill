# 三面三思方法论与评分锚点

本文件把 PRD 中的分析框架压缩为可执行规则。所有分数为 0–100；分数越高不一定越好，必须先看维度方向。

## 1. 三面

### 1.1 基本面 F

基本面回答“资产是否有真实价值和持续需求”，不是只看价格。

必须检查：

- 市值、FDV、流通量、总供应量、最大供应量。
- 未来 30/90/180 天解锁、通胀、团队与机构持仓集中度。
- TVL、协议收入、活跃地址、交易数、稳定币供应、交易所净流。
- 交易所覆盖、衍生品深度、竞争格局与生态发展。
- 宏观环境：利率、CPI/PCE、非农、DXY、美债收益率、全球流动性、美股风险偏好。

评分锚点：

| F | 含义 |
|---|---|
| 80–100 | 价值捕获清晰；TVL/收入/活跃度同步增长；供应与解锁可控；分布健康；宏观顺风 |
| 60–79 | 多数指标偏正面，但存在一项明显弱点或数据不完整 |
| 40–59 | 多空混杂，缺乏可持续证据，或宏观与技术面相互抵消 |
| 20–39 | 基本面走弱：收入/TVL/活跃度下降、通胀或解锁压力明显、集中度高 |
| 0–19 | 逻辑严重受损、数据不可信、重大安全/治理/供应风险 |

关键原则：价格上涨但 TVL、收入和活跃度持续下降时，不能仅凭价格给高 F。

### 1.2 消息面 N

消息面回答“发生了什么、市场是否已定价、事件是否改变原逻辑”。必须同时保留两个量：

- **影响力** `N_impact`：事件有多大，不代表方向。
- **方向**：`Bullish`、`Bearish`、`Neutral`、`Uncertain`。

PRD 的影响力公式：

```text
N_impact = 0.25S + 0.25I + 0.20D + 0.15E + 0.15A
```

其中 S=来源可信度，I=事件重要程度，D=对资产的直接影响，E=市场预期差，A=传播与关注度，均为 0–100。

机会评分中的 `N` 是对多头有利程度，不是影响力本身。建议使用明确的方向映射，并同时展示原始 `N_impact`：

```text
Bullish:  N = 50 + 0.50 * N_impact
Bearish:  N = 50 - 0.50 * N_impact
Neutral:  N = 50
Uncertain: N = 50 - 0.25 * N_impact
```

这样高影响力利空不会被误当成高机会；`Uncertain` 还会降低交易权限。若用户坚持直接用 `N_impact` 代入机会公式，必须在报告中标注该替换会让方向失真，不能据此给出开仓结论。

消息处理流程：

1. 按资产代码、项目名、关键词、来源、发布时间、事件类型、原始链接采集。
2. URL 去重、标题相似度去重、正文语义去重、实体识别；转载不重复计分。
3. 分类为 Regulatory、Macro、Exchange、Institutional、ETF、Security、Tokenomics、Ecosystem、Partnership、Governance、Market。
4. 逐条判断真实性、影响范围、影响方向、影响程度、持续时间、市场预期。
5. 关联价格反应：重大利好不涨、重大利空不跌，都可能是预期已定价或流动性异常。
6. 把“消息影响力”和“方向”分开写入报告。

评分锚点（用于方向映射后的 N）：

| N | 含义 |
|---|---|
| 80–100 | 多条独立高可信来源确认重大利好，且价格/资金尚未完全定价 |
| 60–79 | 偏多事件占优，但仍需价格或资金确认 |
| 40–59 | 中性、混杂或已充分定价 |
| 20–39 | 偏空事件占优，或利好未能推动价格 |
| 0–19 | 高可信重大利空、安全事件或监管冲击 |

### 1.3 技术面 T

技术面回答“什么时候参与、在哪里失效”，必须多周期、量价与结构结合。

核心数据：

- OHLCV、订单簿、逐笔成交、OI、资金费率、多空比、爆仓、基差。
- 1D、4H、1H 为主；15m、5m 只用于执行。
- 指标：MA/EMA、MACD(12,26,9)、RSI14、ATR14、布林带、Volume/OBV/VWAP/CVD、订单簿失衡。

结构判断：

- HH/HL 为上升结构；LH/LL 为下降结构。
- BOS 是结构突破；CHoCH 是市场结构变化。
- 关键支撑/阻力、趋势线、成交密集区、前高前低必须标注来源周期。

评分锚点：

| T | 含义 |
|---|---|
| 80–100 | 多周期趋势一致向上；放量突破/回踩确认；结构完整；衍生品不过热 |
| 60–79 | 偏多但存在周期冲突、量能不足或接近阻力 |
| 40–59 | 震荡、方向不明或信号相互冲突 |
| 20–39 | 多周期偏空、关键支撑失守或反弹无力 |
| 0–19 | 强空头结构、流动性恶化、连续清算或无法定义风险 |

禁止：

- 只凭 RSI>70 做空或 RSI<30 做多。
- 把不同交易所、现货与合约的成交量混为一个指标。
- 用单一周期指标覆盖 4H/1D 的结构。

## 2. 三思

### 2.1 居安思危 W

风险评分越高，风险越大。至少覆盖六类风险：

| 风险 | 检查内容 |
|---|---|
| 市场风险 | 大盘突然下跌、趋势反转、相关性上升 |
| 杠杆风险 | 杠杆过高、保证金不足、强平距离过近 |
| 流动性风险 | 盘口深度不足、滑点扩大、无法止损 |
| 消息风险 | 黑天鹅、政策突变、黑客、交易所异常 |
| 资金风险 | 稳定币脱锚、交易所储备异常、资金费率极端 |
| 资产风险 | 项目衰退、解锁、团队/机构集中、治理问题 |

监控指标：异常波动、ATR 突增、资金费率极端、OI 短时激增、交易所净流入、连续大额清算、高影响利空。

压力测试至少四种：正常上涨、正常下跌、5% 暴跌、10%–20% 极端下跌。逐一回答亏损、保证金、强平距离、流动性、备用退出通道。

评分锚点：

| W | 含义 |
|---|---|
| 0–30 | 风险低且可监控；杠杆、流动性与消息风险可控 |
| 31–60 | 存在明显风险，需要降杠杆、减仓或等待确认 |
| 61–100 | 风险高或不可量化；应暂停新增风险 |

### 2.2 思变 V

思变不是追涨杀跌，而是判断原交易逻辑是否仍成立。

市场状态：强势上涨、弱势上涨、震荡、弱势下跌、极端下跌。

变化级别：

- Level 1：轻微变化，继续观察。
- Level 2：重要变化，重新评估策略。
- Level 3：关键逻辑破坏，减仓或退出。

每次复核必须回答：

1. 与上次相比发生了什么变化？
2. 哪些数据支持变化？
3. 原来的交易逻辑是否仍然成立？
4. 是否需要改变方向、减仓、加仓或退出？

必须保留历史快照：当时基本面、消息面、技术面、计划、风险与后续真实走势。

评分锚点：

| V | 含义 |
|---|---|
| 0–30 | 状态稳定，原逻辑有效，变化可解释 |
| 31–60 | 出现重要变化，需要重新评估或降低频率 |
| 61–100 | 关键逻辑破坏、频繁变脸或数据无法支持原判断 |

### 2.3 思退 E

思退是最高优先级。开仓前必须同时具备：

- 入场价、止损价、止盈目标。
- 仓位大小、杠杆、最大允许亏损。
- 强平价、强平安全距离。
- 交易逻辑失效条件、极端风险退出方案。

仓位公式：

```text
RiskAmount = AccountEquity * RiskPerTrade
PerUnitRisk = abs(EntryPrice - StopPrice)
PositionSize = RiskAmount / PerUnitRisk
Notional = PositionSize * EntryPrice
Margin = Notional / Leverage
```

PRD 示例：账户 10,000 USDT，单笔风险 1%，入场 100,000，止损 98,000，则 `PositionSize=0.05 BTC`；5x 时初始保证金约 1,000 USDT。示例只展示计算，不是行情建议。

止损顺序：固定价格、ATR 动态、结构止损、逻辑止损。执行时必须考虑手续费、滑点、资金费率与极端行情成交风险。

强平规则：

- 止损必须早于强平触发，并保留足够安全距离。
- 不同交易所、全仓/逐仓的强平公式不同，必须读取交易所账户与合约规则。
- 不允许用 LLM 估算强平价替代交易所数据。

评分锚点：

| E | 含义 |
|---|---|
| 0–30 | 退出方案完整、可执行，强平安全距离充足 |
| 31–60 | 方案基本可用，但关键参数或极端流动性仍需验证 |
| 61–100 | 缺少退出方案、止损不可执行或强平距离不足 |

## 3. 综合评分与决策

```text
O = 0.30F + 0.25N + 0.45T
R = 0.35W + 0.30V + 0.35E
```

硬门槛优先于评分：

- 思退方案缺失：禁止开仓。
- 强平安全距离不足：禁止开仓。
- 重大消息真实性无法确认：降低交易权限。
- 交易所数据异常：暂停依赖该数据的决策。
- 原有交易逻辑失效：触发重新评估。

决策表的未覆盖区间按 `score_decision.py` 的保守规则处理，并在报告中说明。

## 4. 数据质量与反向论证

每条关键数据附：来源、更新时间、抓取时间、延迟、是否交叉验证、是否缺失、是否异常。过期新闻不能当作突发利好。

每次看多必须同时列出看空理由，并回答“看多逻辑是否足以覆盖看空风险”。如果答案是否定的，结论不能是“可以评估开仓”。

## 5. 首版范围

优先 BTC、ETH、ICP 的现货与 USDT 永续研究；暂不自动下单。回测、历史决策复盘与权重校准应在数据稳定后进行，不能先用未经验证的权重伪装成高置信度。
